# Contributing

Thank you for helping. These are the defaults for every 3D3D repository. A repository with its own `CONTRIBUTING.md` (for example [Stella Scope](https://github.com/3d3dcanada/stella-scope-community/blob/main/CONTRIBUTING.md)) follows that one instead.

1. **Search first.** Check open and closed issues and pull requests.
2. **Open an issue before a big change** so we can agree on the approach. Small fixes can go straight to a pull request.
3. **Fork, branch from `main`, make one change.** One pull request does one thing.
4. **Run the project's own tests and formatting** before you push, and say how you tested.
5. **Write a clear title and description:** the problem first, then what you changed, then how you checked it. Pull requests are squash-merged, so the title becomes the commit message.
6. **Be patient and kind.** We are a small team and reply within about a week.

By contributing you agree that your work is licensed under the repository's licence, and you confirm you wrote it or have the right to submit it. See the [code of conduct](CODE_OF_CONDUCT.md). Security problems go through [SECURITY.md](SECURITY.md), not public issues.
