# Security policy

We take security reports seriously, across every 3D3D project.

**Please do not open a public issue for a security problem.**

Report it privately in either of these ways:

- On the repository concerned, open the **Security** tab and choose **Report a vulnerability** (where it is enabled).
- Or email **info@3d3d.ca** with the project name in the subject.

Please include what you found, the project and version, how to reproduce it and what you think the impact is. Do not include real passwords, API keys or private files.

We will acknowledge your report, keep you informed while we fix it, and credit you in the release notes if you wish. We ask for a reasonable time to ship a fix before details are published. Only the latest release and the main branch are supported.
