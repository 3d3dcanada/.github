# Getting help

- Read the project's README and documentation first.
- Search existing issues, then open a new one with what you expected, what happened, your version and your system. Remove passwords and keys before you paste anything.
- Security problems: see [SECURITY.md](SECURITY.md).
- Design and print work for customers: [3d3d.ca](https://3d3d.ca) or info@3d3d.ca.
